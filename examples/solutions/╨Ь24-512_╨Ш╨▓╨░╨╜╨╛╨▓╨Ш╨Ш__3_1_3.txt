Номер задания: 3-1
Название: Сумма чисел от 1 до N
Условие: Дано натуральное число N. Найдите сумму всех натуральных чисел от 1 до N включительно.
Используйте цикл for.
Ввод: Натуральное число N (1 ≤ N ≤ 10^6).
Вывод: Сумма чисел от 1 до N.
Решение:
n = int(input())
total = 0
for i in range(1, n + 1):
    total += i
print(total)

Номер задания: 3-2
Название: Факториал
Условие: Вычислите факториал целого неотрицательного числа N.
Ввод: Целое число N (0 ≤ N ≤ 20).
Вывод: Значение N!.
Решение:
n = int(input())
result = 1
for i in range(2, n + 1):
    result *= i
print(result)

Номер задания: 3-3
Название: Таблица умножения
Условие: Выведите таблицу умножения числа N на числа от 1 до K.
Каждая строка имеет вид «N x i = результат».
Ввод: Два натуральных числа N и K, каждое в отдельной строке.
Вывод: K строк таблицы умножения.
Решение:
n = int(input())
k = int(input())
for i in range(1, k + 1):
    print(f"{n} x {i} = {n * i}")
