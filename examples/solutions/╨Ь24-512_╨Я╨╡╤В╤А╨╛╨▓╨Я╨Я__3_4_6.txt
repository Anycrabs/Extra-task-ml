Номер задания: 3-4
Название: Чётные числа в интервале
Условие: Даны целые числа a и b (a < b). Выведите все чётные числа x, для которых a < x < b.
Числа выводятся в одной строке через пробел & в порядке возрастания.
Ввод: Два целых числа a и b, каждое в отдельной строке.
Вывод: Чётные числа из интервала в одной строке через пробел.
Решение:
a = int(input())
b = int(input())

evens = [str(x) for x in range(a + 1, b) if x % 2 == 0]
print(" ".join(evens))

Номер задания: 3-5
Название: Количество цифр
Условие: Определите, сколько цифр в записи целого числа N.
Ввод: Целое число N (может быть отрицательным).
Вывод: Количество цифр числа N.
Решение:
s = input()
print(len(s))

Номер задания: 3-6
Название: Среднее арифметическое
Условие: Дано N, затем N целых чисел. Найдите их среднее арифметическое, округлённое до двух знаков.
Если N = 0, выведите 0.
Ввод: Число N, затем N чисел, каждое в отдельной строке.
Вывод: Среднее арифметическое с двумя знаками после точки или 0.
Решение:
n = int(input())
values = [int(input()) for _ in range(n)]
print(f"{sum(values) / n:.2f}")
