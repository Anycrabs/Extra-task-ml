Номер задания: 2-1
Название: Максимум из двух чисел
Условие: Даны два целых числа. Выведите большее из них.
Ввод: Два целых числа, каждое в отдельной строке.
Вывод: Большее из двух чисел.
Решение:
a = int(input())
b = int(input())
if a > b:
    print(a)
else:
    print(b)

Номер задания: 2-2
Название: Високосный год
Условие: Определите, является ли год високосным.
Год високосный, если он делится на 4 и не делится на 100, либо делится на 400.
Ввод: Натуральное число — год.
Вывод: YES, если год високосный, иначе NO.
Решение:
year = int(input())
if year % 4 == 0 and year % 100 != 0 or year % 400 == 0:
    print("YES")
else:
    print("NO")

Номер задания: 2-3
Название: Наибольший общий делитель
Условие: Найдите НОД двух неотрицательных целых чисел a и b (хотя бы одно из них больше нуля).
Ввод: Два целых числа a и b, каждое в отдельной строке.
Вывод: НОД(a, b).
Решение:
a = int(input())
b = int(input())
while a != b:
    if a > b:
        a -= b
    else:
        b -= a
print(a)
